# Karu Esencial — Diseño web

Landing page para **Karu Esencial**, comercializadora de productos esenciales para el hogar en
Chile (vinagre incoloro, percarbonato de sodio, bicarbonato de sodio; próximamente aceite de
oliva y café en grano). El canal de conversión es WhatsApp: `+56 9 8904 8914`.

## Ver el diseño

Abre `index.html` en el navegador. No necesita compilación ni dependencias.

## Archivos

| Ruta | Contenido |
|---|---|
| `index.html` | Prototipo completo: header, hero, productos, próximamente, beneficios, cómo comprar, testimonios, FAQ, CTA final, contacto, footer |
| `assets/css/karu.css` | Estilos y tokens de diseño (colores, tipografía, espaciado) |
| `assets/js/karu.js` | Interacciones mínimas del prototipo (menú móvil, botón flotante, acordeón) |
| `assets/img/logo-karu-esencial*.webp/png` | Logotipo oficial (original y versión recortada para web) |
| `assets/img/*.svg` | Ilustraciones de referencia para la composición de las fotos |
| `docs/guia-implementacion-wordpress.md` | Cómo construirlo con WordPress + Blocksy Free + Elementor Free |
