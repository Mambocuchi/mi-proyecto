# Karü Esencial — Tema WordPress FSE

Tema de bloques (Full Site Editing) para la landing page de **Karü Esencial**, productos de limpieza naturales.

- `karu-esencial.zip`: archivo listo para subir en **Apariencia → Temas → Añadir nuevo → Subir tema**.
- `karu-esencial/`: código fuente del tema.

Al activarlo, el tema crea la página **Inicio** con la landing completa (editable con bloques nativos) y la define como portada. Más detalles en [`karu-esencial/readme.txt`](karu-esencial/readme.txt).
